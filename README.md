# Townaija

**On-Demand Tow Truck Marketplace for Nigeria.** Stranded motorists name their price and broadcast pickup coordinates; nearby verified tow operators bid or accept; the customer chooses an operator, verifies the job with a 4-digit security code, and tracks the tow in real time. Townaija collects a automated commission from the operator's prepaid wallet upon job completion.

---

## Architecture & Technology Stack

| Layer | Technology | Highlights |
|---|---|---|
| **Mobile App** | React Native (Expo SDK 52) | Unified customer & operator app running on the high-performance Hermes engine. |
| **Backend & Database** | Convex Serverless Platform | TypeScript-first reactive database with end-to-end type safety, real-time WebSocket subscriptions, server-side cron jobs, and file storage. |
| **Authentication** | Convex Auth (`@convex-dev/auth`) | Password-authenticated sessions mapped to phone numbers with cryptographic JWT token issuance and validation. |
| **Maps & Routing** | MapLibre + OpenFreeMap | Free OSM vector tiles and turn-by-turn navigation links via Google Maps. |
| **Operations Console** | Vanilla HTML5 / Modern CSS / ES6+ | Obsidian & Canary Yellow Operations Command portal with live operational metrics and zero external library bloat. |
| **Hosting & CI/CD** | Netlify / GitHub Actions | Static distribution generated via `build_site.py`; automated Android APK builds via GitHub Actions. |

## Security & Product Hardening

Townaija adheres to strict enterprise product security practices:

1. **Zero Information Leakage:** Public client bundles and administrative login screens contain no vendor infrastructure names, backend cloud endpoints, or database identifiers.
2. **Anti-Brute-Force & Rate Limiting:** The Operations Command console enforces progressive client lockout—5 consecutive failed attempts lock the login interface for 60 seconds.
3. **Anti-Enumeration Protection:** Authentication failures return generic messages (*"Invalid administrative credentials or insufficient privileges"*), preventing malicious account and phone probing.
4. **Server-Side Access Control (RBAC):** All administrative queries and mutations (`admin:*`) enforce strict `requireAdmin` validation on the authenticated caller identity. Super-admin elevations (`setAdmin`) are restricted exclusively to verified `super` administrators.
5. **Internalized Mutations:** All administrative seeding scripts and database wipe utilities are defined as `internalMutation` functions, preventing unauthorized execution over public APIs.
6. **Real Operational Data:** All dummy datasets, mock fixtures, and demo toggles have been completely eliminated from the mobile and admin codebases.

## Local Development & Setup

### 1. Prerequisites
- **Node.js** 18+ and **npm**
- **Python** 3.9+ (for static site compilation)
- **Expo Go** or an Android/iOS emulator (for mobile development)

### 2. Backend Setup (Convex)
```bash
cd backend
npm install

# Run local development against Convex cloud
npx convex dev
```

### 3. Mobile App Setup
```bash
cd app
npm install

# Start the Expo development server
npx expo start
```
Scan the QR code with **Expo Go** on Android or camera on iOS, or press `a` to run in the Android emulator.

### 4. Build the Public Website & Admin Console
To compile the landing page and operations console into `dist/`:
```bash
python3 build_site.py
```
To serve locally:
```bash
python3 -m http.server 8080 -d dist
```
- **Landing Page:** `http://localhost:8080/`
- **Operations Command:** `http://localhost:8080/admin/`

## Operating Mechanics

### For Motorists (Customers)
1. **Request a Tow:** Set pickup GPS location and destination; specify vehicle classification, breakdown condition, and key/wheel mobility.
2. **Name Your Price:** View market benchmark fare guidance and submit an initial offer.
3. **Select an Operator:** Nearby operators within 15 km receive the request and submit offers. Choose an operator based on ETA, rating, and vehicle equipment.
4. **Security Start Code:** When the tow truck arrives, verify the operator and provide the unique 4-digit start code to initiate the job.
5. **Direct Settlement:** Pay the operator upon safe drop-off via cash or bank transfer, then confirm delivery on the app.

### For Tow Operators
1. **Onboarding & Verification:** Register vehicle details (wheel-lift, flatbed, heavy-duty), driver license, and inspection documentation.
2. **Prepaid Wallet:** Fund the operator wallet via bank transfer. A minimum balance (default ₦1,000) is required to receive compatible dispatch requests.
3. **Job Dispatch:** Receive nearby compatible jobs within 15 km (automatically expanding to 35 km after 3 minutes if unmatched).
4. **Job Execution:** Submit pre-tow condition photos, verify the customer's 4-digit start code, navigate to drop-off, and capture delivery photos.
5. **Platform Commission:** The platform commission (default 10%) is automatically deducted from the operator's prepaid balance once delivery is confirmed.

## Deployment Configuration

Environment variables configured in Netlify or GitHub Secrets:

| Variable | Description |
|---|---|
| `CONVEX_URL` | Production Convex Cloud URL (e.g. `https://charming-donkey-521.convex.cloud`) |
| `CONVEX_SITE_URL` | Production Convex HTTP Actions URL (e.g. `https://charming-donkey-521.convex.site`) |
| `APK_URL` | Direct download URL for the compiled release APK (e.g. GitHub Releases) |
| `COMMISSION` | Operator platform commission percentage (default: `10`) |
| `SUPPORT_PHONE` | Customer service contact phone number |
| `SUPPORT_EMAIL` | Customer support contact email address |
